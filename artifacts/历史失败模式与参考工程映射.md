# 历史失败模式（只读归类）到抽象参考测试的映射

本表依据历史会话和用户实际体验归纳**失败类别**，不复制任何项目业务规则、计算公式、真实数据或代码到参考工程。

| 历史问题类别 | M0 对应的完全虚构注入 | 当前可检测层 | 尚缺的验证 |
|---|---|---|---|
| 已确认界面字段缺失 | `missing_ui_field.patch` | HTML 静态字段集合检测 **PASS（可识别）** | 线框图自动独立枚举与真实浏览器 |
| API 只返回占位 ID | `empty` 与 `placeholder_api.patch` | 真实 HTTP + 独立七字段断言 **PASS（可识别）** | 多服务契约兼容测试 |
| 导出内容缺列 | `bad_export.patch` | 真实 XLSX XML 与数据校验 **PASS（可识别）** | 浏览器实际下载 |
| 保存成功但数据库未落库 | `no_persistence.patch` | 独立 SQLite 查询 **PASS（可识别）** | 真项目 Testcontainers |
| 页面运行时报错/无法加载 | `ui_crash.patch` | **BLOCKED**（浏览器环境策略） | 干净 Chromium Runner，自动截图/Trace |
| QA 用例仍待测 | `--qa-case pending` | 必验 QA 状态 **PASS（可识别）** | 真实多 Sheet QA 导入与独立审批 |
| 旧版本证据复用 | `--evidence-case stale` | 当前候选 SHA 独立核算 **PASS（可识别）** | 受保护 CI 的身份与部署产物摘要 |
| 修改检查器尝试绕过 | 受限 patch whitelist 单测 | 拒绝非 app 文件修改 **PASS（本地规则）** | 与 Agent 隔离的外部信任根 |
| 开发/QA 需求本身存在遗漏 | 本 M0 手工来源说明与七字段独立评分预期 | **NOT_IMPLEMENTED**（不声称自动发现来源盲区） | M1 多源发现与抽样校准 |
