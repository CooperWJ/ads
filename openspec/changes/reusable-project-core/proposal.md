# 从固定基准走向可复用项目能力

问题：已有 PoC 能校准固定虚构工程，但缺少跨项目接入、标准报告运行、独立 QA 输入与统一状态入口。

本变更提供轻量项目 Profile 与安装 CLI，消费原始来源、已有 OpenSpec/QA 决策和专业报告。派生契约只读，执行记录可重建。复用原生 Agent/测试器/出处工具，不新增 Agent Loop、审批状态机、评测调度平台或生产部署权限。

验收：真实 Python/Node 测试进程；来源/代码/契约/报告漂移拒绝；整场景/整来源缺口拒绝；多 Sheet QA、DEV/QA 分离与必验集合；冷安装；标准构建 provenance。所有模型/权限/独立身份未满足处保留明确阻断，不宣称全 ADS 验收完成。
