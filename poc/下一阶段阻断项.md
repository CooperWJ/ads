# M0 完整验收之前的阻断项

1. **P0 浏览器**：在允许访问本地服务的真实 Playwright Runner 中，`reference --profile full` 必须 PASS，`empty / missing_ui_field / ui_crash / bad_export` 必须 FAIL，等价实现 PASS；保存下载文件及 trace。
2. **P0 可信环境**：在 Docker/Podman 或等价隔离 Runner 中重新评分；开发 Agent 无权读取测试答案、评分器和参考补丁；对作弊修改验证失败。
3. **P0 Harbor**：运行一个自定义任务的真实 Harbor Worker，验证 adapter 输入、结果和 clean rerun，记录版本与开销。若技术不匹配，提供可复现失败报告，再决定替代方案。
4. **P1 Playwright Agents**：在 OpenCode 中实测 planner/generator/healer，验收断言和独立 Oracle 只读；healer 删除断言应阻断。
5. **P1 OpenCode**：实测会话持久化、权限拒绝、Subagent 结果、任务中断与幂等恢复；不得把 CLI 存在当作恢复能力成功。
6. **P1 评测基准**：增加未公开的全新案例；开发集和独立评分集分开，减少固定测试过拟合。

满足以上 P0 前仅可宣称 M0a 后端题目校准通过，不允许宣称完整 M0 完成或 ADS 可用于正式发布。
